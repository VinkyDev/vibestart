## Integration areas [#next]

| Area           | Intended capability                                          |
| -------------- | ------------------------------------------------------------ |
| Observability  | OpenTelemetry traces, metrics, and logs                      |
| AI tools       | MCP configuration and agent skills                           |
| Authentication | Email verification, password reset, and local mail debugging |
| Web            | Internationalization, PWA, and project documentation         |
| Server         | Object storage, caching, and background jobs                 |
| Clients        | Additional desktop and mobile options                        |

These areas are not all implemented. New integrations need defined configuration, dependencies, and compatibility constraints, followed by verification of the relevant combinations. Broader migration support is also planned.

Submit requests and issues on the project’s [GitHub](https://github.com/VinkyDev/vibestart).
