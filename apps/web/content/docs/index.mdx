## What is vibestart? [#what]

vibestart creates full-stack TypeScript applications. You choose a technology for each part of the app, such as the frontend, backend, API, database, and authentication, and vibestart generates a complete project for that combination: application code, tool configuration, tests, and the development conventions that you and a coding agent both follow.

Every combination on offer is generated, installed, checked, tested, and built before release. Once the project exists, the same CLI applies later template updates without overwriting your code.

## What you get [#output]

A generated project is an ordinary repository with no runtime dependency on vibestart. Depending on your choices, it contains:

- **A working application**: pages, an API, a database schema with migrations, and email/password sign-in, connected through a complete todo example.
- **Types end to end**: the database schema, the API, and the pages share TypeScript types, and the server validates every input it receives.
- **Tests of behavior**: browser tests for complete workflows, integration tests for each API operation, and unit tests for branching logic.
- **One set of commands**: `vp run dev`, `vp check`, `vp test`, and `vp run ready` work the same way in every combination.
- **Written conventions**: an `AGENTS.md` that states where each kind of change belongs and when a change is done.
