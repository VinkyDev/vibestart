---
title: Agent Skills
description: Let a coding agent use the vibestart CLI to create and maintain projects.
---

The `vibestart` skill teaches a coding agent how to choose a stack, preview changes, add capabilities, upgrade templates, and finish an upgrade: resolve conflicts and port template changes to starter source. It reads the CLI's current options and structured results before choosing an action.

Installing the skill adds instructions to your agent. It does not install the vibestart CLI, Vite+, or project dependencies. See [CLI overview](/docs/cli) for the current CLI entry point.

## Install [#install]

Run this command from the project where you want the agent to use the skill:

```sh
npx skills add VinkyDev/vibestart --skill vibestart
```

The installer lets you select your coding agent. Installation is project-scoped by default. To select an agent explicitly, append `--agent codex` or `--agent claude-code`. Use `--list` to inspect the source without installing.

The `--skill vibestart` selection installs only the CLI tutorial. Other skills used to develop the generator are not part of this installation. Skill updates and CLI releases are separate: updating one does not upgrade generated projects.

## Use it with your agent [#usage]

Describe the desired result and the target project. For example:

- “Create a vibestart project with a React SPA, Hono, oRPC, SQLite, and authentication. Use pnpm for dependencies and Bun for the Hono runtime.”
- “Add Knip and Docker to this vibestart project. Preserve my application changes.”
- “Preview a template upgrade for this project and explain any conflicts. Do not apply it yet.”
- “Upgrade this project and port the template's changes to the starter source into my code.”

The skill routes creation and maintenance to separate references. It distinguishes previews, deferred installation, and completed checks, so the agent can report what actually ran.

For one session without installation, `skills use` prints instructions and provides a temporary supporting-files directory:

```sh
npx skills use VinkyDev/vibestart --skill vibestart
```

Ask the agent to read the complete output and resolve reference paths from that supporting-files directory. This command does not create or modify a vibestart project.
