---
title: Recover an operation
description: Resume installation, resolve conflicts, or roll back unfinished maintenance.
---

```sh
npx vibestart-cli recover --yes
npx vibestart-cli recover --rollback --yes
npx vibestart-cli recover --abort --yes
```

## Resume [#resume]

`recover` uses the recorded operation without selecting a new target release. Use it after resolving candidate conflicts, fixing check failures, or deferring installation.

## Roll back [#rollback]

`--rollback` restores files, baseline, and lockfiles changed by the unfinished operation. It refuses to overwrite subsequent manual edits. It does not restore `node_modules` or database data; reinstall dependencies when necessary.

Use Git to undo completed upgrades. `recover` does not manage release history.

## Abort [#abort]

`--abort` only applies before project files have been written, such as a plan awaiting conflict resolution. Once files are written, resume or roll back. `--abort` and `--rollback` cannot be combined.
