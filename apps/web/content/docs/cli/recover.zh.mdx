---
title: 恢复操作
description: 继续安装、处理冲突，或回滚未完成的维护操作。
---

```sh
npx vibestart-cli recover --yes
npx vibestart-cli recover --rollback --yes
npx vibestart-cli recover --abort --yes
```

## 继续 [#resume]

`recover` 沿用已记录的操作，不重新选择目标版本。解决候选文件中的冲突、修正检查发现的问题，或完成延后的安装后，用它继续流程。

## 回滚 [#rollback]

`--rollback` 还原当前未完成操作修改的文件、基线与锁文件。发现操作之后的人工修改时，会拒绝覆盖。回滚不还原 `node_modules` 或数据库数据；需要时重新安装依赖。

已完成的升级通过 Git 撤销，`recover` 不管理历史版本。

## 放弃 [#abort]

`--abort` 仅适用于尚未写入项目文件的操作，例如等待解决合并冲突的计划。已经写入文件的操作应继续或回滚。`--abort` 与 `--rollback` 不能同时使用。
