## vibestart 是什么？ [#what]

vibestart 是一个全栈 TypeScript 应用生成器。你为应用的各个部分选择技术，包括前端、后端、API、数据库和认证方式，vibestart 会为这一组合生成完整的项目：应用代码、工具配置、测试，以及你和编码 Agent 共同遵循的开发约定。

所有可选的组合在发布前都经过生成、安装、检查、测试和构建。项目创建之后，同一个 CLI 负责应用后续的模板更新，不会覆盖你编写的代码。

## 项目包含什么 [#output]

生成的项目是一个普通的代码仓库，运行时不依赖 vibestart。根据所选技术，它包含：

- **可以运行的应用**：页面、API、带迁移的数据库结构和邮箱密码登录，由一个完整的待办示例串联起来。
- **贯穿全栈的类型**：数据库结构、API 和页面共享 TypeScript 类型，服务端校验收到的每一项输入。
- **面向行为的测试**：浏览器测试覆盖完整流程，集成测试覆盖每个接口操作，单元测试覆盖分支逻辑。
- **统一的命令**：`vp run dev`、`vp check`、`vp test` 和 `vp run ready` 在所有组合中用法一致。
- **成文的约定**：`AGENTS.md` 写明每类改动应该放在哪里，以及怎样才算完成。

## 在线体验 [#studio]

如果想在安装之前先看看生成结果，可以打开[工作台](/studio)。它在浏览器中组合技术栈，并预览生成项目的每一个文件。
