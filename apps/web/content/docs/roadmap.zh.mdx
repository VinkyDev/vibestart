## 集成方向 [#next]

| 方向       | 预期能力                           |
| ---------- | ---------------------------------- |
| 可观测性   | OpenTelemetry 链路追踪、指标与日志 |
| AI 工具    | MCP 配置与 Agent Skills            |
| 认证扩展   | 邮箱验证、密码重置与本地邮件调试   |
| Web 能力   | 国际化、PWA 与项目文档             |
| 服务端能力 | 对象存储、缓存与后台任务           |
| 客户端     | 其他桌面与移动端选项               |

这些方向尚未全部实现。新增集成需要明确配置、依赖与兼容约束，并通过相应组合的验证。更完整的迁移支持也是后续工作的一部分。

需求与问题可通过项目的 [GitHub](https://github.com/VinkyDev/vibestart) 提交。
